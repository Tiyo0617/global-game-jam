# GlobalGameJam

2D 横版单屏竞技场 Roguelike ｜ Godot 4.5.1 **Mono** (C#) ｜ 48h GameJam

> 玩家只能向**正右方**开炮。赢了敌人变强，输了自己变强。永远不会卡关。

---

## 开工三步

1. **读 `docs/AI_RULES.md`**（10 分钟，项目速览 + 铁律 + 文件所有权红线）
2. **读 `docs/05_任务分派与AI提示词.md`**，确认自己是哪个角色、要做什么
3. **把 `docs/ai_prompts/` 里你那一份整段复制，贴给你的 AI**
   —— 每次开新对话都要重新贴一次，否则你的 AI 会去改别人的代码

## 跑起来

```bash
dotnet build                 # 或 VS Code 里 Ctrl+Shift+B
```
然后在 Godot 编辑器里按 **F5**。

> ⚠️ 编辑器 → .NET → **取消「自动重载项目」**（4.5 的 C# 热重载不稳定）。
> 统一流程：`Ctrl+Shift+B` 编译 → 回 Godot → F5。
